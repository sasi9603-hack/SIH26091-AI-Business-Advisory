# Frontend Application Directory (Planned)

## Overview
This directory is reserved for the SIH26091 user-facing web application and Progressive Web App (PWA).

## Planned Scope & Technology Stack
* **Framework:** React / Next.js (TypeScript)
* **Styling:** TailwindCSS
* **Mapping:** Leaflet.js / Mapbox GL JS (OpenStreetMap rendering)
* **PWA Capability:** Offline caching for regional language forms and cached advisory reports.

## Planned Folder Structure
When development commences, this folder will contain:
```
frontend/
├── public/              # Static assets, icons, manifest.json
├── src/
│   ├── components/      # Reusable UI components (Maps, Charts, Forms)
│   ├── pages/           # App routes & views
│   ├── services/        # API client integration functions
│   ├── styles/          # Global styles & Tailwind configuration
│   └── utils/           # Helper functions & formatting utilities
├── package.json
└── README.md
```
